Adds an import function that runs breseq on input FASTQ read files to populate a sample with mutations and an aligned BAM file. HTML files produced by breseq that show evidence for mutation predictions are also stored so they can be viewed.

Citation: Deatherage, D.E., Barrick, J.E. (2014) Identification of mutations in laboratory-evolved microbes from next-generation sequencing data using breseq. Methods Mol. Biol. 1151:165-188. https://doi.org/10.1007/978-1-4939-0554-6_12
